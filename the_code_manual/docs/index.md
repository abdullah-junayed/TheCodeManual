# Welcome to TheCodeManual 🚀

Your comprehensive guide to mastering web development, systems programming, and professional environment setup. Whether you are writing your first line of markup or debugging memory leaks in C, you have found the right manual.

---

## 📚 What's Inside?

### 🌐 Web Development
Build the modern web from the ground up.
* **[HTML5](html-guide/index.md):** The structural foundation of the web. Learn semantic markup, forms, and document object models.
* **[CSS3](css-guide/index.md):** The visual layer. Master Flexbox, Grid, animations, and responsive design principles.
* **[JavaScript (ES6+)](javascript-guide/index.md):** The interactive engine. Dive into DOM manipulation, asynchronous programming, and modern syntax.

### 💻 Core Programming
Understand how computers execute logic under the hood.
* **[C Programming](c-programming/index.md):** The mother of modern languages. Explore pointers, manual memory management, and foundational data structures.

### 🛠️ Workspace Setup
Your code is only as good as your tools.
* **[VS Code Mastery](vscode-setup/index.md):** Configure the ultimate development environment. We cover essential extensions, keyboard shortcuts, and debugging configurations tailored for both Web and C development.

### 🌐 Command Line Fundamentals

Control your computer like a professional.

- **Linux Command Line (Bash)**: The powerful interface between you and the operating system. Learn file navigation, permissions, process management, shell scripting, pipes, redirection, and system administration basics.
- **Windows Command Prompt (CMD)**: Master the classic Windows terminal environment. Explore commands for file operations, networking, system configuration, batch scripting, and Windows troubleshooting.
- **Terminal Productivity**: Learn efficient workflows with command history, aliases, environment variables, command chaining, and automation techniques.

### 💻 System & Package Management
Understand how software and systems are organized and maintained.

- Nix Package Manager: Experience a modern approach to software management. Learn declarative package installation, reproducible environments, Nix shells, channels, flakes, and dependency management.
- Linux Package Managers: Understand how Linux systems install and manage software using tools like APT, DNF, Pacman, and others.
- Windows Package Management: Explore software installation and updates using tools like Winget, Chocolatey, and PowerShell-based workflows.

## 🗺️ Recommended Learning Path

If you are starting from scratch, we recommend following this progression to build your skills logically:

1. **[Set up VS Code](vscode-setup/index.md)** so you have a professional, highly efficient workspace ready to go.
2. **[Start with Windows Command Prompt (CMD)](./windows-cmd-reference-guide/index.md)** Reference Guide to learn the fundamentals of working with a command-line interface, managing files, running system commands, and understanding how operating systems communicate through terminals.
3. **[Move on to Linux Command Line Reference Guide](./linux-command-line-reference-guide/index.md)** to master powerful shell workflows, file permissions, process management, scripting, networking tools, and everyday system administration tasks.
4. **[Explore Nix Package Manager](./nix-package-manager/index.md)** to learn modern, reproducible software management, isolated development environments, dependency handling, and declarative system configuration.
5. Start with **[HTML](html-guide/index.md)** to understand basic syntax and page structure.
6. Move on to **[CSS](css-guide/index.md)** to learn how to style and position elements.
7. Tackle **[JavaScript](javascript-guide/index.md)** to add logic, math, and interactivity to your web pages.
8. Finally, dive into **[C Programming](c-programming/index.md)** to build a deep, rigorous understanding of computer memory and system-level architecture.
