# What is CSS3?

**CSS** stands for **Cascading Style Sheets**.

CSS is the language used to **style and design HTML webpages**. While HTML creates the structure of a webpage, CSS makes it beautiful by controlling colors, layouts, fonts, spacing, animations, and much more.

Think of it like this:

* **HTML = Skeleton**
* **CSS = Skin, Clothes & Makeup**
* **JavaScript = Brain & Muscles**

Without CSS, websites would look like plain text documents.

---

# What is CSS3?

CSS3 is the **latest major evolution** of CSS.

Instead of releasing one huge version every few years, modern CSS is developed using **modules**. This means new features are added continuously while browsers keep improving support.

CSS3 introduced many powerful features such as:

* Rounded corners
* Shadows
* Flexbox
* Grid Layout
* Animations
* Transitions
* Responsive Design
* Media Queries
* Custom Fonts
* Variables
* Gradients
* Transformations

Today, almost every modern website uses CSS3.

# Who Created CSS?

CSS was created by

**Håkon Wium Lie**

in **1994** while working with Tim Berners-Lee at CERN.

The CSS specification is now maintained by the

**World Wide Web Consortium (W3C)**

along with browser vendors.

# How CSS Works

CSS works using **Selectors** and **Declarations**.

Example

```css
h1{
    color:red;
}
```

Explanation

* **h1** → Selector
* **color** → Property
* **red** → Value

Structure

```css
selector{
    property:value;
}
```

---

# Ways to Add CSS

There are **three ways** to use CSS.

## 1. Inline CSS

```html
<h1 style="color:red;">Hello</h1>
```

Good for testing only.

---

## 2. Internal CSS

```html
<style>
h1{
    color:red;
}
</style>
```

Useful for small projects.

---

## 3. External CSS (Recommended)

HTML

```html
<link rel="stylesheet" href="style.css">
```

style.css

```css
h1{
    color:red;
}
```

This is the professional method used in real projects.

---
