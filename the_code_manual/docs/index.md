# Welcome to TheCodeManual 🚀

Your comprehensive guide to mastering web development, systems programming, and professional environment setup. Whether you are writing your first line of markup or debugging memory leaks in C, you have found the right manual.

---

## 📚 What's Inside?

### 🌐 Web Development
Build the modern web from the ground up.
* **[HTML5](html/index.md):** The structural foundation of the web. Learn semantic markup, forms, and document object models.
* **[CSS3](css/index.md):** The visual layer. Master Flexbox, Grid, animations, and responsive design principles.
* **[JavaScript (ES6+)](javascript/index.md):** The interactive engine. Dive into DOM manipulation, asynchronous programming, and modern syntax.

### 💻 Core Programming
Understand how computers execute logic under the hood.
* **[C Programming](c-programming/index.md):** The mother of modern languages. Explore pointers, manual memory management, and foundational data structures.

### 🛠️ Workspace Setup
Your code is only as good as your tools.
* **[VS Code Mastery](vscode/index.md):** Configure the ultimate development environment. We cover essential extensions, keyboard shortcuts, and debugging configurations tailored for both Web and C development.

---

## 🗺️ Recommended Learning Path

If you are starting from scratch, we recommend following this progression to build your skills logically:

1. **[Set up VS Code](vscode-setup/index.md)** so you have a professional, highly efficient workspace ready to go.
2. Start with **[HTML](html-guide/index.md)** to understand basic syntax and page structure.
3. Move on to **[CSS](css/index.md)** to learn how to style and position elements.
4. Tackle **[JavaScript](javascript/index.md)** to add logic, math, and interactivity to your web pages.
5. Finally, dive into **[C Programming](c-programming/index.md)** to build a deep, rigorous understanding of computer memory and system-level architecture.
