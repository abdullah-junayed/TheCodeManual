# The Ultimate HTML Guide

Welcome to the HTML module of **TheCodeManual**. Before we dive into styling with CSS or adding logic with JavaScript and C, we have to build the foundation. That foundation is HTML.

## Core Concepts

### What is HTML?
HTML stands for **HyperText Markup Language**. It is not a programming language; it is a markup language used to structure content on the web. Think of it as the skeleton of a web page. It tells the browser what is a heading, what is a paragraph, what is an image, and what is a link.

### Who made HTML?
HTML was invented by **Tim Berners-Lee**, a British computer scientist, in 1989. The first official public proposal for HTML was published in 1991. 

### Why was HTML made?
While working at CERN (the European Organization for Nuclear Research), Tim Berners-Lee needed a way for scientists across the globe to easily share, link, and navigate complex research documents over the internet. He created HTML to solve this exact problem, giving birth to the World Wide Web.

### Why use HTML?
You must use HTML because it is the **universal language of the web**. 
* **Structure:** Browsers cannot interpret plain text as a structured website without it.
* **Accessibility:** Proper HTML allows screen readers to interpret the site for visually impaired users.
* **SEO:** Search engines rely on HTML tags to understand what a web page is about so they can rank it in search results.

### What is the current version?
The current version is officially known as the **HTML Living Standard** (formerly referred to as HTML5). It is maintained by the WHATWG (Web Hypertext Application Technology Working Group), a consortium of the major browser vendors. It is continuously updated behind the scenes rather than releasing new, numbered versions.

### Which browsers support it?
HTML is universally supported. Every modern web browser—including **Google Chrome, Mozilla Firefox, Apple Safari, Microsoft Edge, and Opera**—fully supports the HTML Living Standard across all desktop and mobile devices.
